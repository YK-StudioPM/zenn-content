# Zennクロス投稿

サイトの記事をZennへ出すための置き場。

## なぜやるか
案件・スポンサーの実際の経路は「Zenn/Qiitaで記事が伸びる → X経由で企業の担当者からDM」だった
（`../収益化ロードマップ.md` の調査結果）。自サイトのPVより、こちらのほうが直接効く。

## 使い方

```
node to_zenn.mjs                    # 既定の5本を変換
node to_zenn.mjs <slug> <slug> ...  # 記事を指定して変換
```

出力先は `articles/`。**すべて `published: false` で出力される。**

## 人間がやること

1. Zennのアカウントを作る（GitHubアカウントでログイン）
2. GitHubに公開リポジトリを作り、この `zenn/` の中身（`articles/`）を置く
3. Zennのダッシュボード → デプロイ設定 でそのリポジトリを連携する
4. 各記事の `published: false` を `true` に変えてpushすると公開される

## 注意

- **AdSense申請の前に全文を外部へ出すのは避ける。** 同一内容が2箇所にあると重複コンテンツの扱いになりうる。
  申請が通ってから、あるいは記事ごとに時間差をつけて出すのが安全
- 出力の末尾には初出（自サイト）へのリンクが自動で入る。サイト側を正とするため
- Zennにはcanonical URLの設定機能が無いので、上のリンクが実質の役割を果たす
- topicsは最大5個。`to_zenn.mjs` の `META` で記事ごとに指定している
